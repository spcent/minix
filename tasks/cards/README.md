# Task Cards

Use this folder for small, executable work items.

Rules:

- one card per change
- name cards with a sortable numeric prefix
- use `NNNN-short-name.md` for cards that do not belong to a milestone
- use `NNNN-MMMM-short-name.md` for cards that belong to a milestone, where `MMMM` is the milestone id such as `M001`
- put unfinished work in `active/`
- move completed work to `done/`
- reference the relevant files under `specs/`
- do not redefine architecture or dependency rules here

Start from [TEMPLATE.md](./TEMPLATE.md).
